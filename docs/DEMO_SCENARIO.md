# 시연 시나리오 (초안)

2~3분 분량이다. 사용할 단어는 웹캠 시험 결과로 확정한다. 아래 단어는 후보다.

## 등장인물과 기기

| 역할 | 기기 | 화면 |
|---|---|---|
| 환자 (수어) | 노트북 A + 웹캠 | `/patient` |
| 의료진 | 노트북 B 또는 휴대폰 + 마이크 | `/doctor` |
| 진행 | 발표 화면 | 두 화면을 나란히 보여 주거나 화면 공유 |

## 순서

| 시간 | 장면 | 환자 화면 | 의료진 화면 |
|---|---|---|---|
| 0:00 | 연결 | **새 대화 만들기** → 코드 공유 | 코드 입력 → 상단 "● 환자 접속" 확인 |
| 0:20 | 의료진 인사 | "의료진의 메시지"에 자막 | 음성: "어디가 불편하세요?" → 보내기 |
| 0:40 | 증상 1 | 수어 **머리 → 아프다** → 문장 확정 | "머리가 아파요." 표시, 음성 재생 |
| 1:10 | 의료진 질문 | 자막 표시 | 음성: "언제부터 아프셨어요?" |
| 1:30 | 증상 2 | 수어 **어제밤 → 열** (또는 확정 단어) → 문장 확정 | "어젯밤부터 열이 나요." |
| 2:00 | 인식이 틀린 경우 보여 주기 | 틀린 단어를 눌러 후보에서 바꿈 | 고친 문장이 표시됨 |
| 2:20 | 마무리 | | 직접 입력: "진료실로 들어오세요." |

- 단어는 웹캠 시험에서 3번 중 3번 1위로 나온 단어만 쓴다.
- 2:00 장면은 실수를 보여 주려는 게 아니다. 인식이 틀려도 환자가 고칠 수 있다는 기능 시연이다. 실제로 틀리면 이 장면으로 넘어간다.

## 시연 30분 전 확인

- [ ] 두 기기 모두 HTTPS 주소로 접속 (카메라·마이크 권한 허용)
- [ ] 단어 인식 1번, 문장 확정 1번 해서 첫 호출 지연(각 10초 안팎)을 미리 지나 둔다
- [ ] 환자: 책상에 바르게 앉아 허리 위가 다 보이게, 조명은 앞쪽
- [ ] 손을 내린 상태에서 손에 초록 점이 사라지거나 배 아래에 있는지 확인 (자동 자르기 기준)
- [ ] 의료진 기기 소리 켜기 (환자 문장 음성 재생)
- [ ] 발표장 Wi-Fi가 막히면 휴대폰 핫스팟

## 문제가 생기면

| 상황 | 대처 |
|---|---|
| 손을 내려도 인식이 안 됨 | **완료 및 인식**을 누른다. 계속되면 자동 인식 체크를 끄고 버튼 방식으로 한다 |
| 단어가 계속 틀림 | 후보에서 고른다. 그래도 없으면 × 로 지우고 다음 단어로 |
| 음성 인식이 안 됨 | 의료진은 입력창에 직접 쳐서 보낸다 |
| 상대가 "대기 중" | 양쪽 대화 코드가 같은지 확인, 새로고침 |
| 첫 응답이 10초 넘게 걸림 | 정상이다(첫 호출). 미리 깨워 두지 않았을 때 생긴다 |

## 발표에서 같이 말할 것

- 서버 없는 구성(서버리스): 쓰지 않을 때 비용이 거의 들지 않는다
- 개인정보: 영상은 서버로 보내지 않고 좌표만 보낸다. 대화 기록은 24시간 뒤 지워진다
- 한계: 새로운 사람에 대한 정확도는 아직 충분히 재지 못했다. 어휘는 178개다
