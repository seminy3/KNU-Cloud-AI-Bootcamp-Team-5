# ML 규격 및 C920 로컬 확인

ML 자료는 프로젝트와 연결되었습니다. src/ml/points.json은 런타임 포인트 순서이며 tests/fixtures의 두 golden 파일은 검증에 사용합니다. docs/ml은 팀원이 제공한 원문과 Python 기준 구현입니다. 브라우저에서 Python을 실행하지 않습니다.

기본 모델은 public/models/pose_landmarker_full.task 및 hand_landmarker.task입니다. Google 공식 모델 저장소의 float16/1 파일을 사용합니다. 실제 영상은 반전하지 않고 처리합니다.

## 시작

프로젝트 폴더에서 npm ci를 실행한 뒤 start-local.cmd를 실행합니다. Mock 서버(8765)와 프론트(5175)가 각각 열립니다. 이미 Mock 서버가 실행 중이면 새 Mock 창의 포트 사용 오류는 기존 서버를 확인하세요.

http://localhost:5175/session?role=patient 에서 새 대화 만들기 → 통역 화면 열기 → 카메라 켜기 → 브라우저 카메라 허용 순서로 진행합니다. C920을 우선 선택하며, 선택 메뉴에서 다른 장치도 고를 수 있습니다. 장치 변경 후 카메라 다시 연결을 누릅니다. 실제 해상도와 프레임 속도는 장치명 아래 표시됩니다. 요청 해상도는 1280×720, 30fps이며 장치가 실제 제공한 값으로 정규화합니다.

수어 시작 → 한 단어 표현 → 완료 및 인식으로 동작 전체를 수집합니다. 30개가 모여도 중간에 잘라 보내지 않습니다. 15초를 넘으면 해당 동작을 취소합니다. 자동 손내림 감지는 이번 변경에 포함되지 않았습니다.

왼손만 들었을 때 본인의 왼손이 올바르게 배정되는지, 오른손도 같은 방식으로 확인해야 합니다. 실제 모델의 단어 정확도는 AWS 연결 후 따로 검증해야 합니다. 로컬 Mock은 나 → 병원 → 가다 등의 고정 단어를 반환합니다.

## 검증

- TypeScript 검사 통과
- 실제 골든 데이터 50프레임 사용, 최대 좌표 오차 5.51e-7, 요청 23606바이트
- 합성 골든 데이터 6프레임 사용, 최대 좌표 오차 5.52e-7, 요청 20705바이트
- 세션 ID 128자 포함, 소수점 4자리 반올림 기준
- 이 자동화 환경은 esbuild 실행을 spawn EPERM으로 차단하여 Vitest와 브라우저 실기 검증은 사용자 터미널에서 실행해야 합니다.

npm test 및 npm run build로 검사할 수 있습니다. 이전 README의 INPUT_SPEC 미제공 및 모델 파일 미설정 안내는 이 문서로 대체합니다. Cognito, 실제 WebSocket 배포와 기기 간 전달은 별도입니다.
